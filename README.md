# R R Infratech Website

GitHub Pages-ready website for R R Infratech — roads, railways, bridges, building construction and interior works.

## GitHub Pages
1. Create a public GitHub repository.
2. Upload all files and folders, keeping `index.html` in the repository root.
3. Settings → Pages → Deploy from branch → `main` → `/ (root)`.
4. Add `rrinftech.com` under Custom domain after the GitHub Pages URL works.
5. Configure the DNS records shown by GitHub at your domain registrar.

## Before launch
- Replace `info@rrinftech.com` if needed.
- Replace the placeholder phone number in `index.html`.
- Replace the sample SVG project images with your actual project photographs if desired.
- The enquiry form currently points to FormSubmit; verify the receiving email before launch.
